To activate scripts:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope Process

To begin from 0:
    Remove-Item -Force {filenames_to_delete_separated_by_comma} -ErrorAction SilentlyContinue

Generate new keystore:
    python main.py genkeypair -alias {alias} -keystore {keystore}

Verbose keystore info:
    python main.py list -keystore {keystore} -v

Export certificate PEM format:
    python main.py exportcert -alias {alias} -keystore {keystore} -file {certificate}

Inspect certificate:
    python main.py printcert -file {certificate} -v

Delete entry:
    python main.py delete -alias {alias} -keystore {keystore}

Generate CSR:
    python main.py certreq -alias {alias} -keystore {keystore} -file {csr}

pendienteS:
changealias: Modifica el alias (friendlyName) de una entrada existente sin regenerar las claves.

importcert: Importa un certificado público (.crt) al almacén como entrada de confianza (trustedCertEntry).

storepasswd: Permite cambiar la contraseña maestra que protege y cifra el archivo .p12.

--help: Shows the help message and exits.
